# Comparatif des Fonctionnalités : Gratuit vs Premium vs Testeur

Ce tableau détaille les fonctionnalités disponibles pour chaque version de Marcus, afin de vous aider à choisir celle qui convient le mieux à votre communauté.

| Fonctionnalité                      | Gratuit | Premium | Testeur | Description                                                                                             |
| ----------------------------------- | :-----: | :-----: | :-----: | ------------------------------------------------------------------------------------------------------- |
| **Modération & Sécurité**           |         |         |         |                                                                                                         |
| Commandes de Modération             | ✅      | ✅      | ✅      | `/ban`, `/kick`, `/mute`, `/warn`, etc.                                                                 |
| Auto-Modération (Mots-clés, Spam)   | ✅      | ✅      | ✅      | Filtrez les messages indésirables, les liens, le spam de majuscules, etc.                               |
| Logs d'Événements Détaillés        | ✅      | ✅      | ✅      | Journal complet des actions sur le serveur (messages, membres, salons, rôles...).                         |
| Sécurité de Base (Anti-Raid/Bot)    | ✅      | ✅      | ✅      | Protection contre les arrivées massives et les ajouts de bots non autorisés.                            |
| Filtre d'Images IA                  | ❌      | ✅      | ✅      | Analyse les images pour détecter le contenu inapproprié (NSFW, violence...).                            |
| Assistant Modération IA             | ❌      | ✅      | ✅      | Détecte la toxicité dans les messages en temps réel et applique des sanctions.                          |
| Scanner de Liens IA                 | ❌      | ✅      | ✅      | Analyse les liens pour détecter les arnaques, le phishing et le contenu malveillant.                    |
| Système de Captcha                  | ❌      | ✅      | ✅      | Ajoute une étape de vérification pour les nouveaux membres afin de filtrer les raids de bots.           |
| Persistance des Rôles               | ❌      | ✅      | ✅      | Sauvegarde et réattribue automatiquement les rôles d'un membre s'il quitte et revient.                |
| **Engagement & Automatisation**     |         |         |         |                                                                                                         |
| Système de Niveaux & XP             | ✅      | ✅      | ✅      | Récompense l'activité par message, en vocal, et via les réactions.                                      |
| Messages de Bienvenue & Autoroles   | ✅      | ✅      | ✅      | Accueillez les nouveaux membres avec des messages et des rôles automatiques.                            |
| Système de Suggestions              | ✅      | ✅      | ✅      | Permet aux membres de soumettre et de voter pour des idées.                                             |
| Suivi des Invitations               | ✅      | ✅      | ✅      | Suivez qui invite qui sur votre serveur et récompensez les meilleurs recruteurs.                        |
| Système de Tickets (Salons Privés)  | ✅      | ✅      | ✅      | Système de support simple via des salons textuels privés.                                               |
| Hubs Vocaux (Salons Temporaires)    | ✅      | ✅      | ✅      | Permet aux membres de créer leurs propres salons vocaux temporaires.                                    |
| **Fonctionnalités IA Avancées**     |         |         |         |                                                                                                         |
| Assistant Personnel IA (/ia)        | ✅      | ✅      | ✅      | Chaque membre peut poser des questions, corriger du code, etc.                                          |
| Assistant Communautaire IA (/faq)   | ❌      | ✅      | ✅      | L'IA répond aux questions des membres en se basant sur une base de connaissances personnalisée.         |
| IA Vocaux (Noms Dynamiques)         | ❌      | ✅      | ✅      | L'IA renomme les salons vocaux en fonction de l'activité des membres (jeux, stream...).                 |
| Créateur de Contenu IA              | ❌      | ✅      | ✅      | Génère des annonces, des règles et même des images via des commandes simples.                           |
| Constructeur de Serveur IA          | ❌      | ✅      | ✅      | Utilisez l'IA pour créer ou modifier la structure de votre serveur via un bot partenaire dédié.         |
| Agent Conversationnel Personnalisé  | ❌      | ✅      | ✅      | Créez un agent IA avec une personnalité, un rôle et des connaissances spécifiques à votre serveur.     |
| **Commandes Exclusives**            |         |         |         |                                                                                                         |
| Commandes de Masse (/moveall)       | ❌      | ✅      | ✅      | Déplacez ou déconnectez en masse tous les utilisateurs d'un ou plusieurs salons vocaux.               |
| Commandes Testeurs (/mp, /webhook)  | ❌      | ❌      | ✅      | Commandes utilitaires réservées aux utilisateurs ayant le statut "Testeur".                             |
| Commandes Staff (/system, /owner)  | ❌      | ❌      | ❌      | Commandes utilitaires réservées aux utilisateurs ayant le statut "Staff Marcus".                             |
| **-  Et bien plus !!  -**            |         |         |         |L'équipe Marcus vous laissez tout décrvrir par vous même !                                                                                                         |

---

- **Gratuit** : Accès à toutes les fonctionnalités essentielles pour gérer une communauté saine et active.
- **Premium** : Débloque toute la puissance de l'IA pour une automatisation et une sécurité de pointe, ainsi que des fonctionnalités de confort exclusives.
- **Testeur** : Accès à toutes les fonctionnalités Premium, ainsi qu'à des commandes de développement et de test en avant-première. Ce statut est obtenu en boostant le [serveur de support](https://discord.gg/WSpz7FqFsC) ou via des clés spécifiques.
